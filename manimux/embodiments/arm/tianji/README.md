# Tianji arm component

- `arm.py`: shared Marvin session, seven-joint arm channels and offline model entry.
- `kinematics.py`: existing SDK flange FK/IK, joint constraints and DH Jacobian.
- `sdk/marvin/`: ignored local vendor Python bindings, native libraries and configuration.
- `assets/<side>/arm.urdf`: existing runtime visual resource location.
- `assets/marvin/`: ignored source descriptions generated by
  `scripts/assets/prepare_tianji_wuji.py`; these do not replace runtime visuals.

The [Tianji-Wuji contract](../../../../.agents/skills/manimux-development/references/tianji-wuji.md)
owns source preparation, coordinate conventions and the offline geometry audit.
The selected `marvin_waist_mobile` description passes offline comparison with
M6_40 SDK FK. The source grippers are omitted and separate Wuji resources remain
in their owning component. A source-model FK probe is not a control solver.
